# MOSFILM MAP — кликабельный MVP

Статический мобильный веб-прототип для демонстрации концепции навигации и сервисов. Все процессы, расчёты времени, карточки и инструкции внутри интерфейса отмечены как демонстрационные и требуют проверки с ответственными подразделениями Мосфильма.

**Живая версия:** https://naztutnet.github.io/mosfilm-map-prototype/

## Запуск

Из корня проекта:

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory mosfilm-map-prototype
```

Открыть: `http://127.0.0.1:4173/`

## Сценарии

1. Поиск «Павильон №6» и открытие карточки объекта.
2. Обзор маршрута и семь последовательных шагов от главного входа к Павильону №6.
3. Переход GPS → QR, сценарий «Вы здесь» и два шага внутри здания.
4. Сервисы: помещения, питание, актёрские комплексы, ателье, инструкции.
5. Разовый и квартальный пропуск человеку или автомобилю.
6. Офлайн-режим и локальное сохранение как PWA-концепция.

Реальная схема территории используется как визуальная основа. Интерактивный слой поверх неё является прототипом.
